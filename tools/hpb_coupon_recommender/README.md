# HPB 推奨クーポン自動生成ツール

対象店舗（ホットペッパービューティー）の **向こう2週間の空き時間枠** に対して、
**過去8〜9ヶ月の売上明細から分析した売れ筋クーポン** を、枠の空き時間に収まる
施術時間で割り当てて推奨し、**HTML 一覧** を生成します。推奨クーポンは
**価格の昇順** で並びます。

- Python 標準ライブラリのみで動作（追加インストール不要）
- サンプルデータ同梱。実データに差し替えればそのまま使えます

## 使い方

```bash
cd tools/hpb_coupon_recommender

# サンプルデータで生成（成果物/HPB推奨クーポン.html に出力）
python3 recommend.py

# 実データを指定する場合
python3 recommend.py \
  --sales /path/to/売上明細.csv \
  --availability /path/to/空き枠.csv \
  --from 2026-09-02 \
  --out ../../成果物/HPB推奨クーポン.html
```

### オプション

| オプション | 既定値 | 説明 |
| --- | --- | --- |
| `--sales` | `sample_sales.csv` | 売上明細 CSV のパス |
| `--availability` | `sample_availability.csv` | 空き枠 CSV のパス |
| `--out` | `../../成果物/HPB推奨クーポン.html` | 出力 HTML のパス |
| `--from` | 今日 | 対象開始日 `YYYY-MM-DD` |
| `--days` | `14` | 対象日数（2週間） |
| `--top` | `8` | 売れ筋として扱う上位件数 |
| `--per-slot` | `3` | 1 枠あたりの推奨クーポン数 |

## 入力データの形式

### 1. 売上明細 CSV（`--sales`）

過去8〜9ヶ月分。**1 行 = 1 施術（1 会計）** とみなします。

| 列名 | 内容 | 例 |
| --- | --- | --- |
| `日付` | 施術日 `YYYY-MM-DD` | `2026-07-12` |
| `クーポン名` | クーポン名称 | `カット＋カラー` |
| `価格` | 円（整数。`6,600` も可） | `6600` |
| `施術時間` | 分（整数。`90分` も可） | `90` |

クーポンごとに **件数・売上合計** を集計し、価格・施術時間は最頻値を代表値とします。
売上合計の多い順に `--top` 件を「売れ筋」として扱います。

### 2. 空き枠 CSV（`--availability`）

向こう2週間の空き時間枠。管理画面（サロンボード等）からのエクスポートや、
手作業での作成を想定しています。

| 列名 | 内容 | 例 |
| --- | --- | --- |
| `日付` | `YYYY-MM-DD` | `2026-09-05` |
| `開始時刻` | `HH:MM` | `12:00` |
| `空き時間` | 分（その枠に入れられる施術時間の上限） | `120` |

`--from` から `--days` 日間に入る枠だけを対象にします。

## マッチングのロジック

1. 売上明細を集計し、売上上位 `--top` 件を「売れ筋クーポン」とする。
2. 各空き枠について、`施術時間 ≤ 空き時間` の売れ筋クーポンを候補にする。
3. 候補を売上順で `--per-slot` 件まで絞り、**表示は価格の昇順** に並べる。
4. 日付・枠ごとに HTML へ出力。冒頭に「売れ筋クーポン（価格の昇順）」一覧も掲載。

## 空き枠データの取得について（重要）

「向こう2週間の空き状況」は、以下いずれかで用意してください。

- **推奨: 管理画面（サロンボード等）からのエクスポート**
  店舗自身のデータを使うため確実で、規約面も安全です。上記の空き枠 CSV 形式に
  整えてから渡します。
- 公開 HPB ページの自動取得（スクレイピング）は、**サイトの利用規約や HTML 構造の
  変更に依存する**ため本ツールには実装していません。必要な場合は、取得部分
  （`load_availability` に相当する取得関数）を差し替える設計になっています。

## 出力

`成果物/HPB推奨クーポン.html` に、ブラウザで開ける HTML を生成します
（ライト／ダーク両対応・レスポンシブ）。
