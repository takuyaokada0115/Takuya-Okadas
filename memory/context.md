# プロジェクト概要

## 目的

個人タスク管理。メモ・意思決定の記録・作業ログを蓄積し、セッションをまたいで文脈を引き継ぐことを目的とする。

## 運用ルール

このプロジェクトの運用方針は `CLAUDE.md` に定義されている。要点は以下のとおり。

- **セッション開始時**: `memory/` フォルダ内のノートを読んで文脈を把握する。
- **会話中**: 決定事項が出たら、その都度該当ノートに追記する。
- **成果物**: 資料を生成したら必ず `成果物/` フォルダに保存する。

## フォルダ構成

| パス | 役割 |
| --- | --- |
| `CLAUDE.md` | 運用ルールの定義 |
| `memory/` | ノート置き場（本ファイルを含む） |
| `memory/context.md` | プロジェクト概要（このファイル） |
| `成果物/` | 生成した資料の保存先 |
