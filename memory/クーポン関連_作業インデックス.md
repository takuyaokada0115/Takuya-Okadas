# クーポン関連 作業インデックス（SSIN STUDIO 下北沢・町田）

HPB（ホットペッパービューティー）のクーポン表示順まわりの作業が、複数の Claude
チャット・定期タスク・ローカルファイル・リポジトリに分散しているため、
「どれが何をするか・どこにあるか」をここに集約する。毎回探さずに済むように、
新しく関連作業が増えたらこのノートに追記すること。

最終更新: 2026-09-03

---

## 大前提（重要）

- これらの作業は **Claude のチャット（アプリ / claude.ai）** で行われている。
  **Claude Code（ターミナル）ではない**ため、`claude --resume` には出てこない
  （全プロジェクトを `ssin` で検索して0件で確認済み）。
- 会話を探すときは **Claudeアプリのチャット一覧 / 過去チャット検索**で
  `クーポン` `昇順` `町田` `下北沢` `ssin` を検索する。

## 定期タスク（Routine・自動実行）

| タスク名（チャット） | 実行タイミング | 役割 |
| --- | --- | --- |
| **SSIN クーポン並び順 前日18時推奨(下北沢・町田)** | 毎日 18:00頃 | 翌日のクーポン表示順を推奨・通知（両店）。実行履歴に日次で蓄積（22回超）。祝日/連休/月替わり等の特筆がなければ「前日と同様（変更なし）」を返す |
| **HPBクーポン表示順 週次推奨(SSIN町田)** | 週次 | 町田店の表示順を週次で推奨 |
| **HPBクーポン表示順 週次推奨(SSIN下北沢)** | 週次 | 下北沢店の表示順を週次で推奨 |
| **HPBクーポン切替リマインド(当日朝6時)** | 当日 朝6:00 | クーポン切替のリマインド通知 |

> 例）2026/9/2 18:00 配信分 →「明日9/3(木)は平日、両店とも前日と同様（変更なし）。
> 町田は9月版リネーム済み25本、下北沢は平日用30本を継続」。

### メインタスクの定義（「SSIN クーポン並び順 前日18時推奨」の手順）

- **設定**: あなたは SSIN STUDIO（まつ毛パーマ・眉毛Wax サロン。HPB に下北沢店・
  町田店を掲載）のオーナー向けタスク。
- **役割**: 毎日 18:00(JST) に起動し、**翌日の HPB クーポン表示順（サロンボードでの
  並び順）を両店分推奨**する。朝6:00 の「当日切替リマインド」タスクとは別で、
  前夜に並びを準備するためのもの。
- **手順（プロンプト要約）**:
  1. bash で今日・明日・今後7日間の日付と曜日を確認（`TZ='Asia/Tokyo'`）。
  2. 明日と今日の日タイプ（平日/土日祝）を判定。日本の祝日・振替休日は Web 検索で
     必ず確認（ハッピーマンデー等に注意）。今後7日以内に連休（3連休以上、または
     お盆・GW・シルバーウィーク・年末年始）が始まるかも確認。
  3. （以降）日タイプ・イベントに応じて翌日の並びを推奨し、通知する。
- **繰り返し**: 毎日 18:00。**履歴は 8/12 以降ほぼ毎日**（＋手動の「今すぐ実行」記録あり）。
- **状態**: アクティブ（トグル ON）。
