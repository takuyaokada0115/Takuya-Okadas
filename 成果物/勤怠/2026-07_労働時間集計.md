# 2026年7月 労働時間・時間外労働時間集計

- 出典: LINEタイムカード（2026-07、両店舗）
- 計算基準（ユーザー指示）: **実働8時間・休憩1時間**
  - 実労働時間 = (退社 − 出勤) − 休憩60分（各日）
  - 時間外労働時間 = Σ 日次 max(0, 実労働 − 所定8h)
  - 出退勤は実打刻（早出も含む）。LINEの退社訂正メッセージを反映。
- 検証: 谷本さんの時間外18h20mは、6月freee明細の「法定内残業 18:08」とほぼ一致 → **freeeは実働−所定8hで残業を集計**していると判断（従来の「19時超」方式ではない）。

## 時間外手当への影響（★要確認）

従来の給与計算では時間外を「19時以降の退社分」で算出していましたが、上記のとおり**freeeは実働−所定8h**の可能性が高いです。基準を実働−8hに変えると、みなし超過分（=追加で支給する残業）が増えます：

| 氏名 | 旧(19時超)みなし超過 | 新(実働−8h)みなし超過 |
| --- | ---: | ---: |
| 谷本 | 6h12m | 8h20m |
| 山口 | 1h10m | 9h22m |
| 横井 | 3h42m | 5h43m |
| 伊東 | 0 | 0 |

- さらに freee明細では残業が「**法定内残業(1.0倍)**」と「**時間外・法定外(1.25倍)**」に分かれます（6月谷本は全て法定内）。**法定内/法定外の判定ルール（週40h超で法定外 等）**と、みなし残業代が法定内をどこまで充当するかを確定すれば、時間外手当を正確化できます。
