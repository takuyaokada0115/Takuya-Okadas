# HPB クーポン昇順 No. 自動入力ブックマークレット（町田店）

サロンボード等の「入力表」ページで、各クーポン行の **No. 入力欄に昇順の並び番号
（1〜35）を一括入力**するブックマークレットです。35 個の番号を手打ちする作業を
自動化します。

- `bookmarklet.js` … ブラウザに登録する 1 行版（これの中身を使う）
- `bookmarklet.readable.js` … 可読・保守用の整形版（編集用）

## 使い方

1. ブラウザのブックマークを新規作成する。
   - 名前: 例）`クーポン昇順入力（町田）`
   - URL: `bookmarklet.js` の中身（`javascript:` から始まる 1 行）を丸ごと貼り付け
2. サロンボードの並び順「入力表」ページを開く。
3. 作成したブックマークをクリックする。
4. **黄色くハイライトされた行**が書き換わった行。内容を確認する。
5. 問題なければ、ページの**更新（保存）ボタン**を押して確定する。

> ⚠️ このブックマークレットは画面の入力欄を埋めるだけです。**最後に自分で更新
> ボタンを押すまで保存されません。** 必ず内容を確認してから保存してください。

## 並び順やクーポンを変えたいとき

`bookmarklet.readable.js` の `M`（`"クーポン名": No.` の対応表）を編集します。

- **番号 = 昇順の並び順**。1 が先頭。番号を入れ替えれば並びが変わります。
- **クーポン名は途中で切れていても OK**。行に表示される文字列の「一部（先頭〜途中）」
  が含まれていれば一致します（部分一致・空白は無視）。
- 編集後、内容を 1 行に圧縮して `bookmarklet.js` に反映してください
  （改行を除けばほぼそのまま 1 行になります）。

## 注意点（既知の弱点）

- **名前が短く切れていて別クーポンと先頭が被ると、誤った行に入力される**可能性が
  あります。被る場合は、`M` のキーを「他と区別できる位置まで」長くしてください。
- 上から順に**最初に一致した No.** を採用します（1 行 = 1 クーポン想定）。
- 対象は **町田店**のクーポン構成です。店舗・メニューが変わったら `M` を作り直します。
