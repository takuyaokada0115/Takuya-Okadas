# 給与計算エンジン（F1: 総支給まで）

美容サロン給与計算自動化プロジェクトの計算コア。
**総支給（各支給項目の内訳）の算出まで**を担当する。控除（社保・源泉・住民税）は
freee人事労務 に実装済みのため、本エンジンでは計算しない。

## 構成

| ファイル | 役割 |
| --- | --- |
| `incentive.py` | 売上インセンティブ（ルックアップ表）・物販/オプション/指名料コミッション |
| `models.py` | データモデル（Staff/Performance/Attendance）と登録済みスタッフマスタ4名 |
| `payroll.py` | 総支給の計算本体・給与明細整形 |
| `test_payroll.py` | ユニットテスト（境界値・実例） |
| `demo.py` | サンプル実績で全員の明細を出力するデモ |

## 実行

```bash
python3 demo.py          # サンプル明細を表示
python3 test_payroll.py  # テスト（pytest不要の簡易ランナー内蔵）
python3 -m pytest -q     # pytestがあれば
```

## 計算仕様（確定事項）

- **売上インセンティブ**: 総売上（技術+物販+オプション+指名料）で判定するルックアップ表。
  ¥650,000未満=0、¥1,100,000以上=総売上×10%。※¥950,000の行だけ％が飛ぶ(8%)ため表の値をそのまま使用。
- **物販/オプション**: 各5%。**指名料**: 100%（全額）。
- **手当**: 精勤手当（正社員¥5,000）/皆勤手当（有期¥6,900）は契約書どおり支給。
  土日祝手当（有期¥5,000）、店長手当¥20,000（谷本 真澄のみ）。
- **残業**: 固定残業（正社員10h/有期8h）を超えた分のみ追加支給。割増 法定超25%/休日35%/深夜25%。
- **通勤交通費**: 非課税・上限¥30,000。

## 暫定・要確認（★）

- 残業1時間単価の算定基礎（現状: 基本給÷月平均所定労働時間173.8h）。基礎に含める手当・分母日数は要確認。
- インセンティブ表の境界の丸め方（現状: しきい値以上・次未満で下の行を適用）。
- 土日祝手当の支給条件（現状: 月額固定として扱う）。
- 各人の実通勤交通費・freee従業員ID・HPB表示名は未登録（`models.py` の該当欄）。

## 次工程との接続

- 入力: `Performance` は HPB実績（スクレイピング）、`Attendance` は勤怠OCRの集計で差し替える。
- 出力: `PayrollResult` の各支給項目を freee人事労務API へ渡す（F4）。
